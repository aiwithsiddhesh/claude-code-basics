# Repo-Based Practice Labs


This file summarizes the extra hands-on subtopics added to the course. The original lesson pages remain in the app; these labs appear as separate lessons immediately after the related topic. Each lab uses one of the public reference repositories and follows the same pattern: explore, trace, plan, execute, verify, document.

## Reference repositories

- `gothinkster/node-express-realworld-example-app`
- `alan2207/bulletproof-react`
- `realworld-apps/realworld`
- `modelcontextprotocol/example-remote-server`
- `anthropics/skills`
- `anthropics/claude-code-action`

## Student workflow for every lab

1. Fork or clone the repo.
2. Create a dedicated branch.
3. Ask Claude Code to explore before editing.
4. Ask for a plan with exact files.
5. Execute the smallest safe task.
6. Run verification or create a manual test checklist.
7. Inspect git diff.
8. Commit or discard intentionally.
